# 开源素材调研：UI、建模、场景（第 27 轮）

> 本轮需求之一：调研新的开源免费模组（UI / 建模 / 场景），让游戏达到"上线水准"。
> 这份文档记录调研结论、可用的来源，以及**诚实的落地建议**——哪些能安全地立即用，
> 哪些需要单独一轮甚至多轮，哪些本仓库刻意不用。

## 结论一句话

**最适合本项目的是 Kenney 的 CC0 素材包**（本项目跑酷场景已经在用它），其中
`Cube Pets`（24 种方块小动物）和 `Nature Kit`/`City Kit` 是最直接能补"建模简陋、场景简陋"的两类。
但**把程序化生成的宠物替换成导入的 3D 模型，是一次结构性改动**，不是一轮能安全完成的——它牵动
性格/需求/心情/动画/命名/语音几十个测试。本轮先用**不破坏架构**的方式升级（新增 3 个程序化物种），
并把模型替换列为下一阶段的专项。

## 可用来源（都需逐条核对其许可）

| 来源 | 类型 | 许可 | 是否推荐 | 说明 |
|---|---|---|---|---|
| [Kenney.nl](https://kenney.nl/) | 全套（模型/UI/音效/图标） | **CC0 1.0** | ✅ 首选 | 本项目已在用其自然/道具包。`Cube Pets`（24 种动物）、`Nature Kit`、`City Kit`、`UI Pack`、`Game Icons` 全是 CC0、免署名、可商用 |
| [Quaternius](https://quaternius.com/) | 低多边形模型（动物/自然/建筑） | CC0（部分 CC-BY） | ✅ | `Stylized Nature MegaKit`、`Ultimate Modular` 等，低多边形风格与本项目接近；逐包确认 CC0 vs CC-BY |
| [Poly Pizza](https://poly.pizza/) | 低多边形 3D 模型 | CC-BY 为主 | ⚠️ | 量大、风格统一，但多为 CC-BY（需署名），且是单模型不是成套 |
| [Kay Lousberg](https://kaylousberg.com/) | 低多边形模型包 | CC0 | ✅ | `KAY KIT` 系列（自然/建筑/角色），CC0 |
| [itch.io 免费素材](https://itch.io/game-assets/free) | 混杂 | 逐件 | ⚠️ | 质量参差，许可要逐件看，很多是"免费但不可商用" |

UI 方面本项目是 **IMGUI 程序化绘制**（不依赖 Sprite 资源），所以 Kenney 的 UI Pack 不能直接替换，
只能作为**配色/间距/布局的参考**；真正的 UI 升级在本轮是通过"统一面板头部、金币、分区、按钮"完成的。

## 为什么本轮不直接把宠物换成导入模型

1. 宠物不是一张皮：`PetAvatar` 按物种/性格/心情程序化搭身体、耳朵、尾巴、胡须，并驱动**走路、呼吸、
   蹦跳、上窜下跳**这些动画；`PetVoice` 按物种+性格合成叫声。换模型 = 重写这一整条链。
2. 40 多条测试钉在"物种映射、造型部件、八种动物互不相同"上；直接替换会成片变红。
3. "上线水准"是一个持续目标，不是一次替换。正确顺序是：先补**内容**（物种、场景物件），
   再专项做**美术替换**，每步都能测、都能回滚。

## 落地计划（供下一阶段）

- **本轮已做**：新增 3 个程序化物种（小熊猫/小企鹅/小仓鼠），7 种宠物；扭蛋机抽它们。
- **下一阶段候选**：
  1. 用 Kenney `Nature Kit` / `City Kit` 补花园与露台的**静态场景物件**（低风险，替换 `SpawnProp` 的
     素材源即可，和跑酷同一套管线）。
  2. 用 Kenney `Cube Pets` 或 Quaternius 动物**逐步替换** `PetAvatar` 的程序化身体（保留动画骨骼与
     状态逻辑，只换网格与材质），每换一个物种跑一遍测试。
  3. UI 若要从 IMGUI 迁到 uGUI/UI Toolkit，需要单独一轮（涉及所有面板与几十条布局测试）。

## 本仓库的红线（不变）

- 只用**许可明确、可商用、可再分发**的素材（CC0 优先，CC-BY 需署名并记录来源）。
- 逐件记录来源与许可（参考 `THIRD_PARTY.md` / `docs/MUSIC_SOURCES.md` 的格式）。
- 不引入需要登录/Key 的资产仓库，不引入本机路径。

**关键设计决策（下一轮要定的）**

Cube Pets 是**静态单网格**（每只 5–7 个子网格 + 1 张 colormap，**没有骨骼**）。而现在的
`PetAvatar` 是一套**骨骼（头/尾/四条腿）+ 方块网格 + 逐部分动画**（腿摆、摇尾、点头、呼吸、
坐/睡下蹲）。直接换成静态模型会**失去逐部分动画**。下一步二选一：

1. **静态模型 + 简化动画**（推荐先做）：整只模型替代 Rig，保留**上下起伏/转向/蹦跳/下蹲**（靠
   整体 transform + Y 缩放），牺牲腿摆/摇尾/点头的精细度，换来更像动物的外观；
2. **保留骨骼 + 只换网格**：需要分部位（头/身/尾/腿）的 rigged 模型（Quaternius 才有），
   Cube Pets 不是分部位的，做不了这一条。

**下一步**：按映射逐个物种接入，每换一个跑一遍 377 条测试；`PetAvatarTests` 里"造型部件/物种映射"
相关断言可能要跟着改成"模型名正确"。做完验证再 merge 回 `feature/android-mobile`/`main`。
