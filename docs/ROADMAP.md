## 中期（内容与框架）

- [x] **更多小游戏**：七个了——🧩 拼图与 🃏 记忆配对（在屋里玩的面板）、🐦 小鸟飞行、
  🎯 跳一跳、🧺 接果子、🔪 切水果、🐷 弹弓小鸟（各自一个场景）。两种模式都跑通了，加一个 =
  `MiniGameLibrary` 一行 + 一个场景（或一个面板）。第 14 轮把两个新游戏的**手感**补上了
  （接果子滑屏、记忆配对头像/消失/难度），第 15 轮把**造型**补上了
  （接果子是六种基本体搭的水果蔬菜，跳一跳的主角就是玩家养的那只小动物），
  第 16~19 轮把**公平性**补上了（小鸟飞行与弹弓小鸟的关卡都由生成器自己先验证一遍可通关，
  切水果的闯关目标分是"可得分"的一部分），第 20 轮把跳一跳的相机与可达性重做
  （见 DEVLOG 坑 111、112），**第 21 轮给弹弓小鸟装上真物理**：木/石/冰是会翻倒、会压死猪的
  刚体，外加弹弓橡皮筋、可开关的抛物线提示、关卡缓存与不卡画面的异步生成（DEVLOG 坑 114–119）。
- [ ] **弹弓小鸟的拉弓手感**：整屏拖动在真机上有拇指遮挡问题，值得专门一轮实测并调阻力曲线。
- [ ] **再往后的玩法**：候选是"钓鱼"（点/放线的手感）与"找不同"（两张图对比），
  都属于"面板能做"的一类。
- [ ] **宠物社区（联网）**：账号、在线状态、好友、跨用户互动都需要服务端。
  本仓库是纯客户端，这是**另一个工程**，不是下一轮。
- [ ] **宠物的更多物种**：现在是狐/猫/兔/熊，加物种只需在 `PetSpecies.All` 加一项
      （外观 + 人格 + 说话风格）。
- [ ] **更多房间互动**：新的 `InteractableKind` + 行为表一行，即可让宠物自己使用。
- [ ] **虚拟小镇的雏形**：把"一个房间"扩成"几个房间 + 走动"——第 10 轮的多场景
      是这个方向的第一次试探（同一个房间换地方，还不是真正的多房间）。

## 手机端（第 6 轮起）

- [x] **安卓手机适配端**（分支 `feature/android-mobile`）：多点触控层、自适应缩放 HUD、
      安全区避让、两套场景的触屏布局、APK 打包链路。
- [x] **竖屏**：缩放按屏幕短边、相机的宽度适配闭环、玩家设置放开方向，
      竖屏下整个房间与三条车道都在画面里。
- [x] **振动反馈**：轻/中/重三档 + 限流 + 开关，接在换道/跳跃/滑铲、扔捡球、
      宠物回球、撞车、通关上。
- [ ] **真机实测**：目前只用编辑器里的合成手指 + 真机尺寸预览验证过；
      需要在真实手机上装一次，确认帧率、刘海安全区、输入法、返回键，以及**振动的手感**。
- [ ] **发布版签名与商店化**：现在出的是开发版包（未签名、`debuggable`、允许明文 http）；
      要发布得生成 keystore、切 `InsecureHttpOption`、并把大脑端点换成 https。
- [ ] **竖屏的构图打磨**：竖屏为了装下整个房间会把相机退得比较远，宠物显得小；
      可以给竖屏单独做更俯视的全景角度，或让「跟随主角」成为竖屏的默认视角。
- [ ] **横屏之外的其它窗口形态**：折叠屏/平板分屏下的极窄或极宽视口。

## 明确不做

- **用 fal 生成图像/音频**：需要国外信用卡，已用程序化合成 + CC0 素材替代。
- **把语音当成主交互**：第 10 轮做完 TTS 之后，键盘仍然是主入口。语音是补充
  （想听就开），不是"必须先说话才能玩"——那会把一个陪伴游戏变成语音助手。
