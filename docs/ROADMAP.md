# 路线图

按优先级排列。这份列表也是开 issue 的来源——每一条都可以直接变成一条 issue。

## 近期（眼前的完整体验）

- [x] **语音输出（TTS）**：第 10 轮做了——走**手机自带的 `TextToSpeech`**（不用 Edge TTS / SAPI：
  宠物的台词是大模型现写的，预生成音频这条路走不通）。只念说的话、不念括号里的动作，
  并按宠物音色调整 pitch/rate。**还没在真机上听过**。
- [x] **地图与更多场景**：第 10 轮做了——小屋 / 花园 / 夜晚露台，用宠物币解锁，
  场景会改变宠物的衰减曲线与环境光。加第 4 个场景只需在 `RoomThemeInfo.All` 加一条。
- [x] **宠物之间互相交流**：第 10 轮做了——6 种本地文案交换，按两只宠物的性格挑，零 token。
- [x] **扔球的地面落点指示**：第 7 轮做了——预测抛物线（与球同一个积分器）+ 地面落点环，
      环随蓄力收紧。
- [x] **事故与洗澡的完整走查**：第 8 轮补上——占用猫砂盆后膀胱压到临界，
      确实会出事故并在场景里留下污渍，`CleanMess` 能清掉；宽限改成按到盆的距离算，
      并加了 200 秒事故冷却。
- [ ] **TTS 的真机验收**：发音是否自然、延迟多少、切到后台会不会继续念——
  只能在手机上听（代码侧的坑已经在 DEVLOG 坑 56 里堵住）。
- [ ] **事故节奏的真机验证**：200 秒冷却 / 14 秒宽限是按"看着不烦"定的，
      需要在手机上放着跑十几分钟看一次实际频率。
- [ ] **语音输入（STT）**：需要麦克风权限、识别器界面与一整套对话时序，且只能真机验证；
  等 TTS 在真机上验过再评估（两者共用同一套"宠物在说话"的时序）。
- [ ] **宠物对玩家的更多反应**：目前只有"靠近时看你""想你了会走过来"；
      可加"玩家蹲下它凑过来""玩家跑它跟着跑"。
- [ ] **自由视角的软约束**：自由模式目前完全交给玩家，代价是房间近处可能被聊天面板挡住；
      可以做成"自由但保证看得见房间"。
- [ ] **记忆的导出/导入**：现在只能删，没法把日记备份出去再导入（换机就要丢）。

## 中期（内容与框架）

- [ ] **更多小游戏**：框架已经就绪（`MiniGameLibrary` 加一行就是一个活动）。
      小游戏是宠物币的唯一来源，所以它同时是地图与商城的"进货渠道"：
      候选是接果子（左右移动接掉落物）与记忆配对（翻牌找相同）。
- [ ] **宠物社区（联网）**：账号、在线状态、好友、跨用户互动都需要服务端。
      本仓库是纯客户端，这是**另一个工程**，不是下一轮。
- [ ] **宠物的更多物种**：现在是狐/猫/兔/熊，加物种只需在 `PetSpecies.All` 加一项
      （外观 + 人格 + 说话风格）。
- [ ] **更多房间互动**：新的 `InteractableKind` + 行为表一行，即可让宠物自己使用。
- [ ] **虚拟小镇的雏形**：把"一个房间"扩成"几个房间 + 走动"——第 10 轮的多场景
      是这个方向的第一次试探（同一个房间换地方，还不是真正的多房间）。

## 手机端（第 6 轮起）

- [x] **安卓手机适配端**（分支 `feature/android-mobile`）：多点触控层、自适应缩放 HUD、
      安全区避让、两套场景的触屏布局、APK 打包链路。
- [x] **竖屏**：缩放按屏幕短边、相机的宽度适配闭环、玩家设置放开方向，
      竖屏下整个房间与三条车道都在画面里。
- [x] **振动反馈**：轻/中/重三档 + 限流 + 开关，接在换道/跳跃/滑铲、扔捡球、
      宠物回球、撞车、通关上。
- [ ] **真机实测**：目前只用编辑器里的合成手指 + 真机尺寸预览验证过；
      需要在真实手机上装一次，确认帧率、刘海安全区、输入法、返回键，以及**振动的手感**。
- [ ] **发布版签名与商店化**：现在出的是开发版包（未签名、`debuggable`、允许明文 http）；
      要发布得生成 keystore、切 `InsecureHttpOption`、并把大脑端点换成 https。
- [ ] **竖屏的构图打磨**：竖屏为了装下整个房间会把相机退得比较远，宠物显得小；
      可以给竖屏单独做更俯视的全景角度，或让「跟随主角」成为竖屏的默认视角。
- [ ] **横屏之外的其它窗口形态**：折叠屏/平板分屏下的极窄或极宽视口。

## 长期（工程化）

- [ ] **云存档**：日记与记忆现在是本地文件（PlayerPrefs + `persistentDataPath` 下的 JSON）。
- [ ] **CI 跑测试**：`.github/workflows/unity-tests.yml` 已经写好骨架
      （需要 `UNITY_LICENSE` 等 secrets，目前只在手动触发时运行，未配置会优雅跳过）。
- [ ] **选定开源许可**：见 [THIRD_PARTY.md](../THIRD_PARTY.md)。
- [ ] **打包发布**：Windows/macOS 构建产物 + 版本号跟着 `CHANGELOG.md` 走
      （安卓侧已经有 `Tools/DSH Mobile/Build APK`）。

## 明确不做

- **用 fal 生成图像/音频**：需要国外信用卡，已用程序化合成 + CC0 素材替代。
- **把语音当成主交互**：第 10 轮做完 TTS 之后，键盘仍然是主入口。语音是补充
  （想听就开），不是"必须先说话才能玩"——那会把一个陪伴游戏变成语音助手。
